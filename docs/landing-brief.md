# Void to Nova — 랜딩페이지 방향

## 브랜드 한 문장

아직 정해지지 않은 상태에서, 더 나은 다음 상태로.

Void to Nova는 일과 움직임의 작은 불편을 관찰하고, 매일 쓰게 되는 도구로 바꾼다. 우주 소재는 장식이 아니라 `Void → Nova`라는 이동의 은유로 사용한다.

## 사용자를 만나는 방식

- 대상: 새로운 일을 시작하거나 생활의 변화를 만들고 싶은 사람
- 인상: 고급스러움, 절제, 정확함, 조용한 자신감
- 언어: 한국어 중심. 짧고 명확한 문장. 과한 운명·감성 문장과 어려운 영어는 배제
- 시각: 블랙·오프화이트·그레이. 제품의 고유 색만 필요한 곳에 제한적으로 사용

## 랜딩 구성

1. **Opening / Void** — 검은 공간, 깊이를 가진 작은 점들, 스크롤과 함께 시점 앞으로 이동하는 빛.
2. **Wordmark** — 중앙에서 `Void to Nova`가 작게 나타나고 잠시 머문 뒤 화면 밖으로 확대된다.
3. **Brand statement** — 로고가 사라진 자리에 `아직 정해지지 않은 상태에서 / 더 나은 다음 상태로.`를 단단하게 노출한다.
4. **Two lines** — `VOID / 집중을 위한 도구`, `NOVA / 움직임을 위한 도구`를 짧은 소개와 함께 제시한다.
5. **Fast collection** — 11개 제품을 한 장씩 크게 보여준다. 한 제품이 커지고, 정지하고, 다음 제품으로 밀려나는 카탈로그형 전환을 사용한다. 제품 상세페이지의 한국어 헤드라인을 그대로 살린다.
6. **Catalog** — 모든 제품을 빠르게 훑을 수 있는 정돈된 2열/1열 목록. 각 제품은 네이버 스토어로 이동한다.
7. **Closing** — `다음 상태를 고르세요.`와 `네이버에서 제품 보기` CTA. 결제는 사이트에 넣지 않는다.

## 제품 순서

VOID v2: 휴대용 노트북 거치대, 고정형 노트북 거치대, 회전형 노트북 거치대, 맥세이프 휴대폰 거치대, 태블릿 스탠드.

NOVA: 프로틴 쉐이커 블랙, 프로틴 쉐이커 투명, 푸쉬업 패드, 푸쉬업 바, AB 슬라이드, 지압 스태퍼.

## 구현 원칙

- 스크롤은 배경과 콘텐츠가 같은 타임라인을 공유한다.
- 우주 배경은 회전하지 않고 카메라가 앞으로 이동하는 방식으로 보인다.
- 제품 이미지는 제공된 상세페이지 원본을 사용하고, 이미지를 가리는 장식은 최소화한다.
- `NAVER_STORE_URL`을 한 곳에서 바꿀 수 있게 두고, 실제 상품별 URL이 생기면 데이터만 교체한다.
- 모바일에서는 가속 구간을 줄이고 제품 이미지를 먼저 보여주며, `prefers-reduced-motion`에서는 정적인 카탈로그로 동작한다.
